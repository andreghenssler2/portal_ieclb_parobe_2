# Portal IECLB Parobé v0.82.0

## Páginas

- Editor de Páginas recebe o mesmo layout visual do editor de Notícias.
- Nova configuração global em `Configurações > Mídia` para a capa das Páginas.
- Padrão: não mostrar imagem de capa na leitura.
- Resumo deixa de aparecer na leitura individual da Página.
- Resumo continua disponível para SEO.
- Conteúdo legado duplicado com o resumo é tratado na renderização.
- Nova coluna `paginas.exibir_imagem_capa`.
- Páginas existentes são sincronizadas para o padrão global.

- R2: instalador de Mídia mais robusto e reconstrução segura da tag completa da capa das Páginas.
