# Portal IECLB Parobé v0.35.0

## Documentos / Downloads

- Novo módulo administrativo **Documentos / Downloads**.
- Reutiliza arquivos já enviados para a Biblioteca de Mídia; não duplica uploads.
- Categorias próprias para documentos.
- Pesquisa, filtros e paginação de 50 itens no administrador.
- Página pública `/documentos` com busca, categorias e paginação.
- Página amigável `/documento/{slug}`.
- Download amigável `/documento/{slug}/baixar`, com contagem.
- SEO individual e sub-sitemap `documentos.sitemaps.xml`.
- Documentos publicados entram na busca interna do Portal.
- Permissão `documentos.gerenciar` para Administrador, Secretaria e Comunicação.
- Link "Documentos" é acrescentado ao Menu Principal se ainda não existir.
- O arquivo físico da Biblioteca de Mídia não é removido quando um item do catálogo é excluído.
