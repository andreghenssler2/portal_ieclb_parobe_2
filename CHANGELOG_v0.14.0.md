# Portal IECLB Parobé v0.14.0

- Tags para Notícias, com relação N:N.
- Administração em Posts / Notícias > Tags.
- Seleção múltipla de tags no formulário de notícia.
- Página pública `/tag/{slug}`.
- Busca pública em `/busca?q=...` para Notícias, Páginas, Eventos e Galerias.
- Campo de busca no cabeçalho.
- Tags exibidas na notícia pública.
- Tags com notícias publicadas incluídas no sitemap.
