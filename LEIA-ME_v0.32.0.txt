Portal IECLB Parobé - v0.32.0
================================

1. Extraia o ZIP na raiz do Portal.
2. Execute pelo terminal:

   php atualizar_v0.32.0.php

3. Acesse:

   Mídia > Otimização de imagens

Novos uploads de JPEG/PNG/WebP serão processados automaticamente quando a opção estiver ativa.

Para processar a biblioteca já existente:

   php otimizar_imagens_v0.32.0.php

Para regenerar todas as variantes:

   php otimizar_imagens_v0.32.0.php --force

Para limitar um lote:

   php otimizar_imagens_v0.32.0.php --limit=50

O arquivo original nunca é substituído.
