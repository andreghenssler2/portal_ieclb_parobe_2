# Portal IECLB Parobé v0.85.0

## Central de Notificações

- Nova Central de Notificações individual por usuário.
- Badge de não lidas na barra superior.
- Link de Notificações na navegação administrativa.
- Integração automática com a Central de Pendências.
- Respeita permissões do usuário.
- Notificação volta a não lida quando a pendência aumenta.
- Notificações são resolvidas quando a pendência deixa de existir.
- Marcar uma ou todas como lidas.
- Marcar novamente como não lida.
- Abrir diretamente o módulo relacionado.
- Limpeza de notificações antigas resolvidas.
- API `AdminNotificationService::notify()` para módulos futuros.
- Nova tabela `admin_notifications`.
