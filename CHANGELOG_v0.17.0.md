# Portal IECLB Parobé v0.17.0

## Sitemap Index + Imagens

- `/sitemap.xml` passa a ser um índice de sitemaps.
- Sub-sitemaps dinâmicos:
  - `/geral.sitemaps.xml`
  - `/posts.sitemaps.xml`
  - `/paginas.sitemaps.xml`
  - `/eventos.sitemaps.xml`
  - `/galerias.sitemaps.xml`
  - `/tags.sitemaps.xml`
  - `/formularios.sitemaps.xml` (opcional)
- Suporte a aliases no singular (`/post.sitemaps.xml`, etc.).
- Extensão XML de imagens usando `image:image` e `image:loc`.
- Posts e Páginas: imagem destacada + imagens inseridas no editor.
- Eventos: imagem destacada + imagens inseridas na descrição.
- Galerias: capa + até 1.000 fotos do álbum por URL.
- Tags: imagens destacadas das notícias vinculadas.
- Home: logo do portal, quando configurado.
- Tela SEO > Sitemap reformulada com links diretos para cada sub-sitemap.
